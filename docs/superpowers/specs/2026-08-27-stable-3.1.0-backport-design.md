# Stable 3.1.0 Backport Design

## Goal

Create release `3.1.0` from the stable `v3.0.2` tag, carrying the selected
unreleased reliability, performance, filesystem, alignment, and usability
enhancements while preserving the 3.0.2 application architecture.

## Scope

The release starts at commit `4c78bc4`, which is both `v3.0.2` and `master`.
The existing branch `bucky_2026_05_21_23_36_18_UTC` remains unchanged as a
historical source branch; its rejected architecture is not merged wholesale.

### Included behavior

- File browser support for `/Volumes`, removable/ejectable mounted-volume
  metadata, safe eject confirmation, and persistent folders-first sorting:
  `2380636`, `48a1508`, and `e7a0450`.
- File browser action-menu visibility and option-key focus scoping fixes:
  `357073a` and `a68459a`.
- Launcher focus, activation, hotkey presentation, animation timing, cold-open
  scheduling, and interrupted-transition fixes:
  `d0eae3f`, `2676d57`, `e8441a3`, `a9d3636`, `fee48fb`, `fcb1df0`, and
  `5650e9d`.
- Compact native status-menu presentation and its tests: `efc664c`.
- Command-left/command-right mode cycling: `ffb04d7`.
- Shortcut-help pane and its follow-up behavior/layout fixes: `cd5e454` and
  `7061c9c`.
- Tests and documentation directly supporting the included behavior.
- Bundle semantic version `3.1.0` in `packaging/Info.plist`.

### Explicitly excluded behavior

- Moving calculator and dictionary into the Apps stone, dictionary previews,
  prefixed tool routing, shared tool-result presentation, and related image
  lookup changes (`fe9f01b` through `4eb70c8`). Calculator and dictionary
  remain separate stones as they are in 3.0.2.
- Notes/Agenda and reminders, including their command-five stone, storage,
  notifications, and full-pane UI (`81844a1` through `1d8fb39` and related
  Agenda commits). No Notes/Agenda stone is added to 3.1.0.
- Documentation and plan artifacts that describe excluded architecture.
- Later Agenda-removal commits, because the stable base does not contain the
  Agenda feature and therefore has nothing to remove.

## Implementation approach

Use a dedicated branch from `v3.0.2` in an ignored worktree. Apply the included
commits in chronological order where their changes are independent. When a
selected commit was authored against the rejected Apps or Agenda architecture,
reconcile only the intended shared launcher behavior manually and keep the
3.0.2 calculator/dictionary boundaries intact. Do not delete the source branch.

The final tree must contain no `Agenda` source, no new Apps routing for
calculator/dictionary, and no user or repository-specific private data.

## Data flow and safety

The backport keeps existing asynchronous indexing and file-browser loading
generation guards. New mounted-volume operations remain explicit, limited to
volumes marked removable or ejectable by macOS, capability checked, and
confirmation gated. Existing weak captures, cancellation paths, and bounded
preview behavior must remain in place so the backport does not add retained UI
cycles, unbounded work, or unsafe filesystem actions.

## Verification

- Run `swift test` and require zero failures.
- Run a release build/bundle and verify `CFBundleShortVersionString` is exactly
  `3.1.0`.
- Inspect the final diff against `v3.0.2` for the explicit exclusions and for
  accidental PII or unrelated files.
- Confirm the original source branch and working tree remain unchanged.
