# Stable 3.1.0 Backport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconstruct a stable 3.1.0 release from v3.0.2 with selected filesystem, launcher reliability, performance, alignment, mode-navigation, and shortcut-help enhancements while excluding the Apps calculator/dictionary merge and Notes/Agenda architecture.

**Architecture:** Work only in the isolated agent/release-3.1.0-stable-backport branch rooted at v3.0.2. Apply independent file-browser and UI changes from their source commits, manually reconcile launcher fixes authored after excluded architecture changes, and keep calculator/dictionary as separate launcher modes. The source branch bucky_2026_05_21_23_36_18_UTC remains untouched.

**Tech Stack:** Swift 5.9, SwiftUI/AppKit for macOS 26, XCTest, Makefile release bundle, XML packaging/Info.plist.

**Spec:** docs/superpowers/specs/2026-08-27-stable-3.1.0-backport-design.md

## Global Constraints

- Base the release on signed stable tag v3.0.2 at commit 4c78bc4.
- Set CFBundleShortVersionString to exactly 3.1.0.
- Keep calculator and dictionary as separate stones; do not add Apps-prefixed routing, dictionary previews, or Commons image lookup.
- Do not add Notes/Agenda source, storage, reminders, notifications, or a command-five stone.
- Preserve asynchronous generation guards, cancellation, weak captures, bounded preview work, and confirmation gates for filesystem operations.
- Do not commit PII, private domains, customer/company details, generated build artifacts, or unrelated rejected-feature documentation.
- Use signed conventional commits; the local pre-commit hook is unavailable because ggshield is not installed, so use --no-verify only when that hook blocks the signed commit and record the limitation.
- Every task ends with a focused test or diff check before its commit.
